# 10.2.1 release

- Adds an Agent Configurator to InferPage — create, edit, and chat with persisted agents in the web UI, with live tool-call and reasoning-token streaming.
- Adds opt-in MCP server support for agents, off by default, enforced both in the UI and at run time.
- Adds a built-in tool catalog (web search, calculator, current datetime, etc.) with rehydration after agent reload.
- Bundles Node.js/npx into Docker images for MCP servers, and persists agent data across container restarts.
